# 01 — CRM de Ventas con IA

Kanban comercial + scoring de leads + asistente que redacta seguimientos. Enfocado a **equipos de ventas**.

## 🚀 Deploy en Vercel (desde monorepo)
- Repo: tu `portfolio-fullstack-ia`
- **Root Directory:** `frontend_projects/01-crm-ventas-ia`
- Framework: Next.js · Build: `npm run build`

## 💻 Local
```bash
npm install
npm run dev
# abre http://localhost:3000
```
